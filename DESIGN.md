# Design

The review workspace uses a calm paper background, dark green text, and restrained green actions. A split layout places the transcript beside extracted orders; selected evidence is shown below in the original turn order. On narrow screens the panels stack. The active engine and the research scope stay visible, and a transcript edit invalidates previous results.

Core tokens: background `#f5f4ef`, ink `#182f2e`, accent `#236c59`, surface `#ffffff`, and border `#d8dfd8`. Body text uses a system sans serif; the headline uses a serif display face. Controls expose keyboard focus and evidence state.
